# LowPoly Rush: 3D Roguelite Endless Runner

Бесконечный 3D-раннер на Three.js с механикой инверсии гравитации, процедурной генерацией коридоров и биомов, битвами с боссами, магазином прокачки и скинов.

---

## 🏗 Архитектура и структура проекта

Проект полностью рефакторизован из монолитного HTML в модульную архитектуру по слоям ответственности:

```text
3d-runner/
├── index.html                   # Корневой HTML с разметкой UI/HUD и модальных окон
├── package.json                 # Скрипты запуска/сборки и зависимости (Three.js, Vite)
├── vite.config.js               # Конфигурация бандлера Vite
├── src/
│   ├── main.js                  # Входная точка приложения, инициализация игры
│   ├── config/                  # Игровой баланс, физика и справочники
│   │   ├── gameConfig.js        # Константы скоростей, таймингов, полос и гравитации
│   │   ├── biomes.js            # Палитры и параметры биомов (освещение, туман, цвета)
│   │   ├── skins.js             # Конфигурация скинов персонажа и цветовых схем
│   │   ├── upgrades.js          # Список улучшений магазина и одноразовых бустов
│   │   ├── achievements.js      # Список достижений, условий и наград
│   │   └── quests.js            # Конфигурация ежедневных миссий
│   ├── services/                # Сервисный слой
│   │   ├── StorageService.js    # LocalStorage с валидацией, миграцией и сбросом
│   │   ├── AudioService.js      # Процедурный синтезатор звуков и адаптивной музыки (Web Audio API)
│   │   └── InputService.js      # Унифицированный обработчик ввода (клавиатура, жесты/свайпы, тач-кнопки)
│   ├── core/                    # Игровое ядро и движок
│   │   ├── Engine.js            # Инициализация Three.js (Scene, Camera, Renderer, ACES Filmic, свет)
│   │   ├── CameraManager.js     # Плавное следование за игроком, динамический FOV при Nitro, Screen Shake
│   │   ├── ParticleSystem.js    # Пул частиц (Object Pool) для эффектов взрывов, искр и нитро
│   │   ├── CollisionSystem.js   # Система AABB и радиальных коллизий (препятствия, монеты, магниты, лазеры)
│   │   └── Game.js              # Главный координатор игры и стейт-машина (MENU, PLAYING, PAUSED, GAMEOVER)
│   ├── entities/                # Игровые 3D сущности
│   │   ├── PlayerModel.js       # Процедурная low-poly модель с иерархией суставов и скелетной анимацией
│   │   ├── Player.js            # Физика, смена полос (lerp), прыжки, подкаты, флип гравитации, бластер
│   │   ├── MiniBoss.js          # Модель и паттерны атак босса-дрона (hover, плазменные сферы, шкала HP)
│   │   └── LevelGenerator.js    # Процедурный стриминг чанков, пол/потолок, декорации, монеты и бонусы
│   ├── ui/                      # Модули пользовательского интерфейса
│   │   ├── UIManager.js         # Координация экранов, плашек алертов и индикаторов HUD
│   │   ├── ShopModal.js         # Магазин с табами (Upgrades, Skins, Boosts)
│   │   ├── AchievementsModal.js # Модальное окно достижений и клейма наград
│   │   ├── QuestsModal.js       # Модальное окно ежедневных квестов
│   │   └── SettingsModal.js     # Настройки громкости, качества графики и тач-падов
│   └── styles/
│       └── main.css             # Стили оформления, шрифты, неоновые эффекты, glassmorphism
```

## 🚀 Примененные паттерны и подходы

1. **Object Pool (Пул объектов)** — частицы (`ParticleSystem`) и чанки уровня (`LevelGenerator`) повторно используются без частой аллокации памяти и вызовов GC.
2. **State Machine (Машина состояний)** — четкое разделение состояний игры: `MENU`, `PLAYING`, `PAUSED`, `GAMEOVER`.
3. **Separation of Concerns (Разделение ответственности)** — сервисы (`StorageService`, `AudioService`, `InputService`), визуальный движок (`Engine`, `CameraManager`), физика и коллизии (`CollisionSystem`), сущности (`Player`, `MiniBoss`, `LevelGenerator`) и интерфейс (`UIManager`) изолированы друг от друга.
4. **Single Source of Truth (Единый источник истины)** — конфигурация вынесена в `src/config/`.
5. **Procedural Web Audio** — синтез звуков на базе Web Audio API без внешних аудио-файлов, адаптивный темп саундтрека в зависимости от скорости раннера.
6. **Camera Shake & Dynamic FOV** — процедурный screen shake с затуханием при получении урона/взрывах и динамический угол обзора (FOV) при активации Nitro.

## 🎮 Управление

- **Смена полос:** `A` / `D` или `←` / `→` (или свайпы влево/вправо на экране)
- **Прыжок:** `Space` / `W` / `↑` (удерживайте для более высокого прыжка, нажмите в воздухе для двойного прыжка)
- **Подкат:** `S` / `↓` (уменьшает рост персонажа для прохода под лазерами, быстро опускает на землю из воздуха)
- **Инверсия гравитации:** `Shift` / `G` (переворот между полом и потолком коридора)
- **Супер-ускорение (Nitro):** `Ctrl` / `F` (неуязвимость и максимальная скорость при заряде энергии)
- **Пауза:** `Escape` / `P`
- **Тач-интерфейс:** встроенные экранные кнопки управления на смартфонах и планшетах
